# JVM-Android: Step by Step

## 1. Identify the artifact

```bash
file target.*                       # Java archive / Dalvik dex / Android package / class
unzip -l app.apk | head             # APK is a zip: classes.dex, lib/<abi>/*.so, resources.arsc
```

## 2a. JAR or .class

```bash
javap -c -p -s Klass.class          # raw bytecode, private members, type signatures
# full-source view:
cfr app.jar --outputdir src_cfr     # or: procyon -o src_proc app.jar
```
Read `javap` when a decompiler emits code that would not recompile (synthetic methods, obfuscated
control flow); the bytecode is the ground truth.

## 2b. APK

```bash
jadx -d out_jadx app.apk            # DEX to Java, the quickest overview
apktool d app.apk -o out_apktool    # smali + decoded resources + AndroidManifest.xml
# alternative route to the Java decompilers:
unzip app.apk classes.dex -d .; d2j-dex2jar classes.dex -o app.jar; cfr app.jar --outputdir src
```
Start at the manifest `MAIN`/`LAUNCHER` activity and follow the flow. Check `assets/` and
`res/raw/` for embedded blobs.

## 3. Find the real check

- **Custom ClassLoader**: a class that extends `ClassLoader` and calls `defineClass(byte[])` is
  loading a hidden class. Rebuild the `byte[]` (often XOR-decrypted) and it is a normal `.class`
  starting with `CAFEBABE`.
- **Native method**: a method marked `native` resolves into `lib/<abi>/*.so`. Find it by its
  static name `Java_<pkg>_<Class>_<method>`, or in the `RegisterNatives` table set up in
  `JNI_OnLoad`. Reverse the `.so` in Ghidra; the first two args are `JNIEnv*` and `jobject`.

## 4. Dynamic analysis

```bash
# JVM: break where the check happens
jdb -attach <port>                  # stop in the method, print locals
```
```js
// Frida: hook a Java method and observe or override its result
Java.perform(() => {
  const C = Java.use('com.pkg.Checker');
  C.verify.implementation = function (s) {
    console.log('input=', s);
    const r = this.verify(s);
    console.log('result=', r);
    return r;
  };
});
```
For a native method that needs a real `JNIEnv`, drive it with Frida on-device, or emulate with
Unicorn if you only need the pure computation.

## 5. Confirm

Reproduce the check offline (recompute the expected value, or recover the loaded class) and verify
it matches before trusting the result.
