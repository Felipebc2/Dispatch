# Audio-Signals: Context for Claude

Quick competition reference for audio that carries data. The role here is to read the spectrogram,
name the mode, and run the matching decoder (or hand-roll an FSK demod when the tools will not lock).

## Decision flow

```
Render a spectrogram first (sox ... spectrogram). What does it look like?
 ├─ two alternating tones (FSK) → minimodem (Bell 202 = 1200 baud 1200/2200 Hz; Bell 103 = 300)
 ├─ packet-like FSK bursts      → multimon-ng -a AFSK1200 (AX.25/APRS) on 22050 Hz mono raw
 ├─ tone pairs                  → multimon-ng -a DTMF
 ├─ slow swept image            → SSTV (qsstv)
 ├─ on/off bursts               → Morse (threshold the envelope)
 └─ tools will not lock         → Goertzel FSK demod in numpy, then frame 8N1
```

## Quick-reference commands

```bash
soxi sound.wav                                   # rate, channels, duration
sox sound.wav -n spectrogram -o spec.png         # identify the mode visually
sox sound.wav -r 22050 -c 1 clean.wav            # normalize to mono, common decoder rate
minimodem -r -f clean.wav 1200                   # Bell 202 FSK (try the baud you measured)
sox clean.wav -r 22050 -e signed-integer -b 16 -t raw - | multimon-ng -t raw -a AFSK1200 -
sox clean.wav -r 22050 -e signed-integer -b 16 -t raw - | multimon-ng -t raw -a DTMF -
```

## Common failure modes (and the cause)

| Symptom | Likely cause |
|---|---|
| minimodem prints nothing | wrong baud, or mark/space swapped; try the other baud and invert |
| multimon-ng silent | it needs 22050 Hz mono signed-16 raw; pipe through sox first |
| Output is bit-inverted text | polarity flipped; swap the mark/space (or the f0/f1 comparison) |
| Decodes only half | data is on one stereo channel; `remix 1` to isolate it |
| Garbled framing | not 8N1, or no resync on the start bit; align each byte to a start edge |
| Nothing demodulates | it is not a modem: DTMF/SSTV/RTTY look different; or it is audio stego, not FSK |

## When to flag that demodulation is not the vector

- The flag is in metadata or appended bytes: `exiftool`/`binwalk`/`strings` first.
- The payload is hidden in the samples (LSB/phase): that is audio steganography, a stego vector.
- The spectrogram draws readable text: just read the image, there is nothing to decode.
