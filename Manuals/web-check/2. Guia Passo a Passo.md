# Web Check: Step by Step

Practical workflow from a target URL to a filtered report. Concepts in
`1. Fundamentos e Quando Usar.md`.

## 1. Run the report (browser)

Open `https://web-check.xyz/check/<target>` (for example
`https://web-check.xyz/check/example.com`). The public instance blocks scripted access (Vercel
checkpoint, HTTP 429), so this step runs in a browser.

Then download the JSON from the page's export option: it saves as `web-check-results.json`.

## 2. Shrink the JSON before reading it

The raw export is large: a measured report was **721 KB**, of which 446 KB is the Lighthouse audit
(`quality`) and 129 KB is a base64 screenshot (`screenshot`). Neither helps in a CTF.

```bash
F=~/Downloads/web-check-results.json

jq -r 'keys | join(", ")' "$F"                     # which checks are present
jq -c 'del(.quality, .screenshot)' "$F"             # everything else (~12 KB)

# Only the CTF-relevant keys (~5 KB); missing keys are simply skipped
jq -c 'with_entries(select(.key | IN("dns","txt-records","robots-txt","sitemap","linked-pages",
  "headers","cookies","redirects","security-txt","ssl","ports","server-info","tech-stack",
  "whois","subdomains","archives")))' "$F"

# Checks that failed or were skipped (re-check those by hand)
jq -r 'to_entries[] | select((.value|type)=="object" and (.value.error or .value.skipped)) | .key' "$F"
```

## 3. Read it for leads

- `robots-txt` / `sitemap` / `linked-pages`: paths to request next (`curl -s http://<target>/<path>`).
- `dns` / `txt-records`: TXT values (flags, base64, hints); hostnames to pivot on.
- `ssl.subjectaltname`: other hostnames on the same certificate (`DNS:*.example.com` = wildcard).
- `headers` / `cookies`: custom `X-` headers, a JWT in a cookie (go to `Arsenal/WEB/jwt-alg-none`),
  a server/framework version (look it up with `--toolset net/vuln-db`).
- `ports`: services beyond HTTP worth a look.

## 4. Confirm locally

Treat the report as leads, not proof: re-request anything interesting with `curl`/`dig` before
building on it (the target may have changed since the scan).
