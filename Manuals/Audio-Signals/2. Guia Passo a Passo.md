# Audio-Signals: Step by Step

## 1. Inspect the file

```bash
soxi sound.wav                      # sample rate, channels, duration, encoding
sox sound.wav -n spectrogram -o spec.png   # look at it before guessing the mode
```
Read the spectrogram: two alternating horizontal lines means FSK (a modem); short tone pairs mean
DTMF; a slow swept pattern means SSTV; on/off bursts mean Morse.

## 2. Normalize if needed

```bash
sox sound.wav -r 22050 -c 1 clean.wav          # resample to mono, a common decoder expectation
sox sound.wav clean.wav remix 1                # keep only the left channel if the data is on one
sox sound.wav trimmed.wav trim 1.5 10          # cut to the burst (start 1.5s, length 10s)
```

## 3. Decode by mode

### FSK modem (Bell 202 / Bell 103)
Bell 202 is 1200 baud, mark 1200 Hz, space 2200 Hz. Bell 103 is 300 baud.
```bash
minimodem -r -f clean.wav 1200                 # try the baud rate; add 1200 for Bell 202 default
minimodem -r --rx-one -f clean.wav 300         # Bell 103
```

### AFSK1200 packet (AX.25 / APRS), POCSAG, DTMF
`multimon-ng` wants raw 22050 Hz mono signed 16-bit:
```bash
sox clean.wav -r 22050 -e signed-integer -b 16 -t raw - | multimon-ng -t raw -a AFSK1200 -
sox clean.wav -r 22050 -e signed-integer -b 16 -t raw - | multimon-ng -t raw -a DTMF -
```

### SSTV
Play into qsstv (or use an offline SSTV decoder) and read the rendered image.

## 4. Fallback: a hand-written FSK demodulator

When minimodem will not lock (odd baud, noisy), measure energy at the two tones per bit window with
a Goertzel filter and threshold:

```python
import numpy as np, scipy.io.wavfile as wav
sr, x = wav.read('clean.wav'); x = x.astype(float)
if x.ndim > 1: x = x[:, 0]
baud, f0, f1 = 1200, 1200.0, 2200.0          # adjust to the observed tones/baud
N = int(sr / baud)
def goertzel(block, f):
    k = 2*np.cos(2*np.pi*f/sr); s0=s1=s2=0.0
    for s in block: s0 = s + k*s1 - s2; s2, s1 = s1, s0
    return s1*s1 + s2*s2 - k*s1*s2
bits = []
for i in range(0, len(x)-N, N):
    b = x[i:i+N]
    bits.append(1 if goertzel(b, f1) > goertzel(b, f0) else 0)  # flip if polarity is inverted
# then frame as 8N1 (start bit 0, 8 data LSB-first, stop bit 1) and resync on each start edge
print(''.join(map(str, bits[:64])))
```
Adjust `f0`/`f1`/`baud` to the tones you measured, and flip the comparison if the output is
inverted.

## 5. Confirm

A valid decode is self-evident (readable text, a clean APRS frame). If it is garbled, revisit the
baud, the mark/space assignment, and mono vs stereo before blaming the tool.
