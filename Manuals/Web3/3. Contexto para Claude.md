# Web3 / EVM: Context for Claude

Quick competition reference for **blockchain (EVM/Solidity)** challenges. Goal: given an
`instance.json` (a Paradigm-style launcher) or a contract address, decide the vector and execute it
via terminal/script. The toolchain is already installed:

| Tool | Binary / venv | What for |
|---|---|---|
| **heimdall** 0.9.2 | `~/.cargo/bin/heimdall` (on PATH) | decompile bytecode → approximate Solidity, CFG, decode calldata, dump storage |
| **Foundry** 1.8.5 | `~/.config/.foundry/bin/{cast,forge,anvil,chisel}` | `cast` = RPC/tx Swiss Army knife; `anvil` = local fork; `forge` = exploit in Solidity; `chisel` = REPL |
| **web3.py** 8.0.0 | `~/.venvs/web3/bin/python` | Python scripting when `cast` falls short |

> ⚠️ Foundry isn't on the PATH of non-login shells. Use the full path
> (`~/.config/.foundry/bin/cast`) or make sure to `export PATH="$PATH:$HOME/.config/.foundry/bin"`.

## 1. Always first: read `instance.json` and map the target

The launcher usually gives a JSON with `uuid`, an `rpc endpoint`, a `private key` (an account with
ETH), a `setup contract`, and sometimes a `player address`. Extract everything:

```bash
cat instance.json          # rpc, privkey, Setup address
RPC="<rpc url>"            # e.g. http://host:8545/<uuid>
PK="<private key>"
SETUP="<setup addr>"
CAST=~/.config/.foundry/bin/cast

$CAST chain-id --rpc-url "$RPC"                         # confirm the chain (CTF uses 31337)
$CAST balance $($CAST wallet address --private-key $PK) --rpc-url "$RPC"
```

The **Setup** creates the target contract and defines the victory condition. Read its getters:

```bash
$CAST call $SETUP "TARGET()(address)"   --rpc-url "$RPC"   # or challenge()/instance()
$CAST call $SETUP "isSolved()(bool)"    --rpc-url "$RPC"   # objective = make it true
```

## 2. Get the bytecode and understand the contract (no source)

```bash
$CAST code <addr> --rpc-url "$RPC" > target.bin           # on-chain bytecode
heimdall decompile <addr> --rpc-url "$RPC"                # approximate Solidity
heimdall disassemble "$(cat target.bin)"                  # EVM opcodes
heimdall cfg <addr> --rpc-url "$RPC"                      # control-flow graph
$CAST interface <addr> --rpc-url "$RPC"  2>/dev/null || true  # ABI if verified/4byte
```

Decode unknown calldata/return: `heimdall decode <calldata>` or
`$CAST 4byte <0xselector>` / `$CAST 4byte-decode <calldata>`.

## 3. Vector decision tree

```
Secret "hidden" in a private variable / storage
  → NOT private on-chain: $CAST storage <addr> <slot> --rpc-url $RPC
  → mapping slot: cast index <keyT> <key> <slot_base>  → then storage at that slot
  → heimdall dump <addr> --rpc-url $RPC  dumps the whole storage

Function gated by msg.sender / tx.origin / require(caller == X)
  → call from the right account; if it checks tx.origin, route via an intermediary contract

commit-reveal / stored hash (keccak(secret) == stored)
  → read the hash in storage, crack it offline if weak, or front-run the reveal

Reentrancy (external call before updating the balance/state)
  → exploit in forge: an attacker contract with a fallback that re-enters

delegatecall / proxy with colliding storage
  → overwrite the owner/implementation slot via a colliding layout

Arithmetic / unchecked / type casts
  → overflow/underflow to bypass a balance/limit require

msg.value / price / manipulable oracle
  → flash-loan-like or unbalance the pair to fool getPrice()
```

Never assume a vector outside this without flagging that it's an undocumented hypothesis (project
rule).

## 4. Execute the attack transaction

A simple state call (free, view): `cast call`. A state-changing transaction: `cast send`.

```bash
$CAST send <addr> "solve(uint256)" 1337 --private-key $PK --rpc-url "$RPC"
$CAST send <addr> --value 1ether "deposit()" --private-key $PK --rpc-url "$RPC"
$CAST send <addr> 0x<raw_calldata>         --private-key $PK --rpc-url "$RPC"  # raw
```

An exploit with a contract (reentrancy/intermediary): a `forge script` draft:

```bash
FORGE=~/.config/.foundry/bin/forge
# Exploit.s.sol uses vm.startBroadcast(PK); new Attacker(target); attacker.go();
$FORGE script Exploit --rpc-url "$RPC" --private-key $PK --broadcast
```

web3.py when you need fine tx logic/assembly:

```python
# ~/.venvs/web3/bin/python expl.py
from web3 import Web3
w3 = Web3(Web3.HTTPProvider("<RPC>"))
acct = w3.eth.account.from_key("<PK>")
# ... build/sign/send_raw_transaction ...
```

## 5. Close it out: confirm victory and get the flag

```bash
$CAST call $SETUP "isSolved()(bool)" --rpc-url "$RPC"    # should turn true
```

With `isSolved()==true`, the launcher releases the flag (a `/flag` endpoint with the instance's
token/uuid, or the service hands it over itself). Always validate against the CTF's configured flag
format before declaring.

> Time tip: `anvil --fork-url $RPC` brings up a local fork to test the exploit freely without
> spending the remote instance or hitting a rate limit: rehearse on the fork, fire at the target.
