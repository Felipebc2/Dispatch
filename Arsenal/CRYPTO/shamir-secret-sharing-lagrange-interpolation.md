## How to recognize this pattern

- Points `(x, y)` called shares, a prime modulus `p`, and a threshold `t` ("any 3 of 5", "k-of-n").
- The secret is the constant term `f(0)` of a hidden polynomial of degree `t - 1` over `GF(p)`
  (threshold 3 means a quadratic, threshold 2 a line).
- Often padded with decoys: a "posted secret" larger than `p`, an "extra point" not on the curve.

## Method

Interpolate exactly `t` shares at `x = 0`, modulo `p`:
```python
def lagrange_at(pts, x0, p):            # f(x0) mod p from points [(x, y), ...]
    s = 0
    for i, (xi, yi) in enumerate(pts):
        num = den = 1
        for j, (xj, _) in enumerate(pts):
            if j != i:
                num, den = num * (x0 - xj) % p, den * (xi - xj) % p
        s = (s + yi * num * pow(den, -1, p)) % p
    return s

secret = lagrange_at(shares[:t], 0, p)
assert all(lagrange_at(shares[:t], x, p) == y % p for x, y in shares[:t])
```
Sage one-liner: `PolynomialRing(GF(p), 'x').lagrange_polynomial(shares)(0)`.

**More than `t` shares, some possibly wrong:** interpolate every `t`-subset and keep the polynomial most
shares agree with (Berlekamp-Welch does the same in polynomial time if there are many shares):
```python
from itertools import combinations
def robust_secret(shares, t, p):
    best = None
    for sub in combinations(shares, t):
        agree = sum(lagrange_at(sub, x, p) == y % p for x, y in shares)
        if best is None or agree > best[0]: best = (agree, lagrange_at(sub, 0, p), sub)
    return best    # (agreeing shares, secret, subset used)
```
Decode with `long_to_bytes(secret)` if it should be text.

## Gotchas

- Use exactly `t` points for degree `t - 1`. Folding an extra point in raises the degree and silently
  gives a different `f(0)`. Check any extra point against the recovered polynomial before trusting it.
- The secret lives mod `p`: a "posted" value `>= p` cannot be `f(0)` (reduce it to confirm it is a decoy).
- A share with `x = 0` is the secret itself; two shares with the same `x` mean a typo or a trap.
- Fewer than `t` shares is information-theoretically secure unless the coefficients are weak: small
  (brute force), derived from the secret or from a seeded PRNG (see the LCG entry), or `p` is tiny.
- No modulus given: try the integer/rational interpolation (`fractions.Fraction`); integer coefficients
  leak the secret directly, and a non-integer result means a modulus is hidden somewhere.
- NOT this pattern: points generated by `y = g^x mod p` (discrete log) or a matrix system with more
  unknowns than a polynomial (generic linear algebra).
