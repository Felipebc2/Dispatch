# CrackStation / Hashes.com: Step-by-Step Guide

Practical workflow for identifying and trying to crack a challenge hash. Concepts in
`1. Fundamentos e Quando Usar.md`.

## 0. Identify the hash type first

The hash length (in hex characters) already indicates the most likely algorithm:

| Length | Likely algorithm |
|---|---|
| 32 | MD5 |
| 40 | SHA1 |
| 56 | SHA224 |
| 64 | SHA256 |
| 96 | SHA384 |
| 128 | SHA512 |
| 32 (NTLM format, Windows context) | NTLM |

Tool to confirm when ambiguous:
```bash
pip install name-that-hash
name-that-hash -t "<hash>"
```

## 1. Lookup on CrackStation

1. Go to https://crackstation.net
2. Paste the hash(es) into the box (accepts multiple, one per line)
3. Solve the captcha, click **Crack Hashes**
4. The result shows the detected type + plaintext (if found)

## 2. Lookup on Hashes.com

1. Go to https://hashes.com/en/decrypt/hash
2. Paste the hash, select the type (or leave auto-detect on)
3. If it isn't found in the free lookup, there's the option of submitting it to their cracking
   service (it takes time, it's not instant, and it's usually not worth the wait during a timed
   competition; prefer local cracking if the instant lookup fails).

## 3. If neither one found it: local cracking with hashcat

```bash
# Install (if you don't have it yet)
sudo pacman -S hashcat   # Arch
# or: apt install hashcat

# Identify the hashcat mode (-m) for the algorithm
hashcat --help | grep -i "md5\|sha1\|sha256" | head -20

# Run against rockyou (the most common wordlist in CTF)
hashcat -a 0 -m 0 hash.txt rockyou.txt      # -m 0 = MD5
hashcat -a 0 -m 100 hash.txt rockyou.txt    # -m 100 = SHA1
hashcat -a 0 -m 1400 hash.txt rockyou.txt   # -m 1400 = SHA256

# View what's already cracked
hashcat -m 0 hash.txt --show
```

The rockyou wordlist (if you don't have it locally):
```bash
locate rockyou.txt 2>/dev/null || find / -iname "rockyou.txt*" 2>/dev/null
# Kali already ships with it at /usr/share/wordlists/rockyou.txt(.gz)
```

## 4. Salted hash (format `hash:salt`)

When the challenge gives the salt alongside it:
```bash
echo 'hash:salt' > hash.txt
hashcat -a 0 -m <salted_mode> hash.txt rockyou.txt
```
The `<salted_mode>` depends on how the salt is combined (`salt+password` vs. `password+salt`).
Check `hashcat --help` by the algorithm name + "salted" to find the right mode (e.g. `-m 20` is
`md5($salt.$pass)`, `-m 10` is `md5($pass.$salt)`).

## 5. Rules/mutation (a password "almost" in the dictionary)

If plain `rockyou.txt` doesn't find it, try with rules (capitalizes, adds common numbers/symbols):
```bash
hashcat -a 0 -m 0 hash.txt rockyou.txt -r /usr/share/hashcat/rules/best64.rule
```
