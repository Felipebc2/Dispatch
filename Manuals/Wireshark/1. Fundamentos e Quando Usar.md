# Wireshark / tshark — Fundamentals and When to Use It

Manual for analyzing captured traffic (`.pcap`/`.pcapng`) with Wireshark (GUI) and tshark (CLI).
Walkthrough in `2. Guia Passo a Passo.md`; competition reference in `3. Contexto para Claude.md`.

## What it is

**Wireshark** is the standard network-protocol analyzer — it opens a capture file and dissects
each packet by protocol. **tshark** is the command-line version (same engine), ideal for
scripting/batch filtering and for terminal use by Claude.

- GUI (Wireshark): best for exploring visually, following streams, exporting objects.
- CLI (tshark): best for grep/automation, extracting specific fields, running without a graphical
  environment.

## Key concept: display filters

The power is in the **display filters** (syntax `http.request`, `ip.addr == x`, `tcp.port == 21`).
They're the same in the GUI (the filter bar) and in tshark (`-Y '<filter>'`). Mastering half a
dozen solves most network-forensics CTFs.

## When it's worth using

- **FOR**: any `.pcap`/`.pcapng` attachment — it's the base tool for finding credentials,
  transferred files, commands, or the flag in a payload.
- Reconstructing a session (HTTP, FTP, Telnet, IRC) via **Follow Stream**.
- Extracting transferred files (images, binaries, documents) with **Export Objects** and then
  analyzing them with binwalk/stego.

## When it's NOT worth it

- A **100% TLS capture with no key** — without an `SSLKEYLOGFILE`/private key among the
  attachments, it won't decrypt; find the key first, otherwise the vector is something else.
- A file that's **not a network capture** (despite the extension) — run `file` first; it may be a
  stego container or a memory dump (then it's Volatility, not Wireshark).
- A single, obvious payload already visible in `strings` — sometimes
  `strings file.pcap | grep -iE 'flag'` solves it without opening Wireshark.

## Tools that go with it

- **`tcpflow` / `tcpxtract`** — reconstruct flows/files outside Wireshark.
- **`binwalk` / `strings` / `file`** — analyze the objects exported from the capture.
- **`NetworkMiner`** — automatic extraction of files/credentials from a pcap (a friendly
  alternative).
- **Volatility** — if the "pcap" is actually a memory dump, or if the challenge combines network +
  memory.
