# RsaCtfTool: Context for Claude

Quick competition reference. Runs via the terminal (`python3 RsaCtfTool.py ...`). The role here is
to **read the parameters (`n`,`e`), identify the likely attack, and target it directly** instead of
waiting for the full sweep, and to fall back to a manual decrypt when all that's left is building
`d`.

## Decision flow (look at n and e first)

```
openssl rsa -pubin -text -in key.pem -noout   → read n (bits) and e
 ├─ small n (<~512b) ..................... factor (FactorDB) → --attack factordb/qicheng
 ├─ e = 3 + ciphertext ................... --attack low_exponent / root (m^e < n)
 ├─ huge e (~n) .......................... --attack wiener / boneh_durfee (small d)
 ├─ same n, two (e,c) .................... --attack common_modulus
 ├─ same m, several (n,c), small e ....... --attack hastads
 ├─ p,q close ............................ --attack fermat
 └─ none of these / strong RSA ........... NOT key cracking, look for another vector
                                            (padding oracle, key leak, signature)
```

## Quick-reference commands

```bash
# inspect
openssl rsa -pubin -text -in key.pem -noout

# recover the private key / decrypt
python3 RsaCtfTool.py --publickey key.pem --private
python3 RsaCtfTool.py --publickey key.pem --decrypt cipher.bin
python3 RsaCtfTool.py -n <N> -e <E> --uncipher <C>

# specific attack (faster)
python3 RsaCtfTool.py --publickey key.pem --private --attack wiener
python3 RsaCtfTool.py --list-attacks

# common modulus / hastad
python3 RsaCtfTool.py -n N -e E1 --uncipher C1 -e2 E2 --uncipher2 C2 --attack common_modulus
```

Manual decrypt (you already have p,q):
```python
from Crypto.Util.number import inverse, long_to_bytes
d = inverse(e, (p-1)*(q-1)); print(long_to_bytes(pow(c, d, n)))
```

## Gotchas to remember in the moment

- **Check FactorDB first** (http://factordb.com): if `n` is already factored, the rest is a
  manual decrypt in seconds; no need to sweep at all.
- `e=3` without padding only yields to the root attack if **`m^e < n`** (a short message);
  otherwise it's Håstad/something else.
- Wiener requires a **small `d`** (hence a large `e`); if `e=65537` and `n` is large, it's not
  Wiener.
- 2048-bit RSA with `e=65537` and padding **won't break**: if the challenge insists on strong
  RSA, the vector is implementation/protocol (oracle, reuse, signature), not the key.
- Flag when the math is **trivial by hand**, since it's not worth the tool's round-trip.
