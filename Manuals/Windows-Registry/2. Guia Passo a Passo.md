# Windows-Registry: Step by Step

## 0. Replay transaction logs first

A hive dumped from a live system can be dirty. Apply the `.LOG1`/`.LOG2` logs before parsing, or you
may read stale values:

```bash
registry-transaction-logs SYSTEM --log SYSTEM.LOG1 --log SYSTEM.LOG2 -o SYSTEM.clean
```
Work from the clean hive from here on.

## 1. Orient: which ControlSet is current

```bash
regipy-dump SYSTEM -p '\Select'          # Current = N  -> use ControlSet00N
```

## 2. ShimCache (AppCompatCache): programs the system saw

```bash
# Eric Zimmerman:
AppCompatCacheParser.exe -f SYSTEM --csv . --csvf shim.csv
# regipy plugin:
regipy-dump SYSTEM -p shimcache
```
Path: `SYSTEM\ControlSet00N\Control\Session Manager\AppCompatCache`. Each entry has a path and a
FILETIME. That timestamp is the executable's last-modified time, not an execution time. Presence
plus ordering is the signal, not a run clock.

## 3. Autostart and services (persistence)

```bash
regipy-dump SOFTWARE -p '\Microsoft\Windows\CurrentVersion\Run'
regipy-dump SOFTWARE -p '\Microsoft\Windows\CurrentVersion\RunOnce'
regipy-dump SYSTEM   -p '\ControlSet001\Services'     # look for odd ImagePath values
```

## 4. Execution evidence beyond ShimCache

```bash
regipy-dump SYSTEM   -p bam                           # BAM/DAM: last run time per executable
regipy-dump NTUSER.DAT -p userassist                  # GUI program launches (ROT13 encoded names)
AmcacheParser.exe -f Amcache.hve --csv . --csvf amc.csv   # SHA1 + full paths, strong evidence
```

## 5. User activity

```bash
regipy-dump NTUSER.DAT -p shellbags                   # folders browsed, including removable/deleted
regipy-dump NTUSER.DAT -p '\Software\Microsoft\Windows\CurrentVersion\Explorer\RecentDocs'
```

## 6. Dependency-light fallback

When the tools above are missing, a small `python-registry` script reads any key:

```python
from Registry import Registry      # pip install python-registry
reg = Registry.Registry("SYSTEM")
key = reg.open("ControlSet001\\Control\\Session Manager\\AppCompatCache")
print(key.value("AppCompatCache").value()[:64])   # raw blob; parse the 10ts/entry format
```

## 7. Cross-check before you answer

Confirm a finding against a second artifact (ShimCache path against Amcache SHA1, a service against
its on-disk binary) so a single decoy entry does not mislead you.
