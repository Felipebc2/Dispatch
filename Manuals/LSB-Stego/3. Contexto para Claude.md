# LSB Steganography: Context for Claude

Quick reference. Unlike CrackStation/Hashes.com, here there's a local executable script
(`Manuals/LSB-Stego/steglsb.py`): Claude runs it directly via `Bash`, it's not a manual flow.

## Decision flow

```
1. Broad recon first: file/exiftool/strings/binwalk/zsteg on the suspicious image
2. Does zsteg already point to a suspicious bit-plane? -> skip to step 4 with the suggested `bits`
3. No clue about `bits`: run decode in a loop from 1 to 8 (see command below)
4. Decode: python3 "Manuals/LSB-Stego/steglsb.py" -d <image> <bits> <out.png>
5. Open each generated output: wrong bits = noise; right bits = recognizable image/QR/text
6. Output is a QR code -> zbarimg; output has text -> read directly or OCR (tesseract)
```

## Quick-reference commands

```bash
# Recon before assuming LSB
file imagem.png && exiftool imagem.png && binwalk imagem.png && zsteg imagem.png

# Decode varying bits (you don't know ahead of time which was used in the encode)
for b in 1 2 3 4 5 6 7 8; do
    python3 "Manuals/LSB-Stego/steglsb.py" -d suspect_image.png $b "out_bits${b}.png"
done

# Read a QR code in the decoded output
zbarimg out_bitsN.png

# Encode (only needed to test/understand the mechanism, rare in solving)
python3 "Manuals/LSB-Stego/steglsb.py" -e cover.png secret.png <bits> out.png
```

## Stopping conditions / when it's NOT this vector

- The image is a **JPEG** (lossy): LSB doesn't survive compression; don't burn the 8 bit
  iterations in that case, flag to the user that the format rules out this vector.
- All 8 `bits` 1-8 outputs are noise: it's probably not pure LSB (image-inside-image); consider
  `steghide`/`zsteg` with a password or another channel (audio, metadata) instead of pushing on
  with the same script.
- An unsupported image mode (`P`, palettized): convert to `RGB` first
  (`Image.open(...).convert("RGB")`) instead of assuming the script failed for some other reason.

## Related tools (outside this manual's scope)

- **`zsteg`:** covers LSB generically in PNG/BMP with more heuristics (multiple channels/planes
  automatically). Run it first as triage.
- **`steghide`:** steganography with a password, arbitrary data (not image-inside-image). Use it
  when the hidden payload isn't itself an image.
- **`stegsolve`:** a Java GUI for visually inspecting bit-planes, useful when the automated script
  isn't conclusive.
