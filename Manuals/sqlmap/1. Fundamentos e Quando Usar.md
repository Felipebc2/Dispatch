# sqlmap: Fundamentals and When to Use It

Manual for `sqlmap`, the automator for detecting and exploiting SQL injection. Walkthrough in
`2. Guia Passo a Passo.md`; competition reference in `3. Contexto para Claude.md`.

## What it is

`sqlmap` (https://sqlmap.org) is the standard tool for detecting and exploiting SQLi. Give it an
injection point (URL, POST parameter, cookie, header) and it figures out the injection type and the
DBMS on its own, and extracts data (databases, tables, columns, content) without you writing a
payload by hand.

## Key concept: it needs the right request

sqlmap is only as good as the request you give it. The most reliable way is to capture the real
request (Burp/DevTools), save it to a file, and pass it with `-r`: that way cookies, headers, and
body go exactly as the app expects. A loose URL with `-u` works for a simple GET.

## SQLi types it covers

- **Boolean-based blind**: the response changes (true/false) depending on the condition.
- **Error-based**: the app leaks the DBMS error, which carries the data.
- **UNION-based**: injects a `UNION SELECT` to bring columns straight into the response.
- **Time-based blind**: no visible difference in the response; it infers from timing (`SLEEP`).
- **Stacked queries**: multiple queries (`; DROP ...`), when the driver allows it.

## When it's worth using

- **WEB** with a parameter that smells like a query (`?id=1`, a search, a login) and a response
  that changes with `'`/`"`.
- When the injection is **blind** (boolean/time): extracting by hand is slow and tedious; sqlmap
  automates it.
- Enumerating the schema/dumping a table quickly after confirming the injection point.

## When it's NOT worth it

- A **trivial and visible** SQLi (e.g. `' OR '1'='1` already logs you in): solving it by hand is
  faster than configuring sqlmap (solving by hand is often faster than an AI round-trip).
- The vector **isn't SQL**: NoSQL (Mongo), SSTI, LDAP, XPath need a different approach; sqlmap is
  no good.
- An aggressive WAF/filter that requires a specific hand-crafted payload: sometimes a tuned manual
  `UNION` gets through where sqlmap stumbles (use it as a complement, with `--tamper`).

## Scope caution

Target **only the challenge's target**. Don't point sqlmap at the CTF platform's infrastructure:
the event rules prohibit attacking the platform (always check them first). `--batch` fires
everything without asking; be aware of that in a competition environment.

## Tools that go with it

- **Burp Suite / DevTools**: capture the request to feed `-r`.
- **`ffuf`/`gobuster`**: find the endpoint/parameter before injecting.
- **jq / CyberChef**: process the extracted data (decode/format).
