# LSB Steganography: Step-by-Step Guide

Practical workflow for decoding (or encoding, if you need to test) an image with `steglsb.py`.
Concepts in `1. Fundamentos e Quando Usar.md`.

## 0. Broad recon first (before assuming LSB)

```bash
file imagem.png
exiftool imagem.png
strings imagem.png | grep -i "flag"
binwalk imagem.png
zsteg imagem.png            # already covers LSB in PNG/BMP, bits 1-4, several channels
```

If `zsteg` already shows suspicious data in a specific bit-plane, you already have the clue for how
many `bits` to use in step 2, so skip straight there.

## 1. Install the dependency

```bash
pip install Pillow
```

The script (`steglsb.py`) is standalone, no installation needed: it only needs Pillow in the environment.

## 2. Decode (the most common CTF case: extract what was hidden)

```bash
python3 steglsb.py -d suspect_image.png <bits> out.png
```

- `<bits>`: the number of least significant bits used in the original encode (**you don't know it
  ahead of time**; test from 1 to 8):
  ```bash
  for b in 1 2 3 4 5 6 7 8; do
      python3 steglsb.py -d suspect_image.png $b "out_bits${b}.png"
  done
  ```
- Open each generated `out_bitsN.png`: the right `bits` produces a recognizable image (the flag
  may be in the extracted image itself as text, a QR code, etc.); the wrong ones produce pure
  noise.

## 3. If the output is a QR code or an image with text

```bash
# QR code:
zbarimg out_bitsN.png
# or open it visually and read it by hand if small

# Text in the image:
tesseract out_bitsN.png stdout   # OCR, if the font is legible
```

## 4. Encode (rarely how you solve in CTF, more useful for testing/understanding the mechanism)

```bash
python3 steglsb.py -e cover.png secret.png <bits> out.png [mode]
```

- `cover.png`: the visible/public image
- `secret.png`: the image to hide (it must have a compatible mode; the script converts it
  automatically to the cover's mode)
- `mode` (optional): forces `RGB`/`RGBA`/`L`/`CMYK` if auto-detection fails

## 5. If `imagem.mode` is unsupported

The script only accepts `RGB`, `RGBA`, `L`, `CMYK`. If the image comes in another mode (e.g.
palettized `P`), convert it first:
```python
from PIL import Image
img = Image.open("imagem.png").convert("RGB")
img.save("imagem_rgb.png")
```
