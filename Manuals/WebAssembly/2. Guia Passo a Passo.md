# WebAssembly: Step by Step

A practical path from a `.wasm` file to understanding (or driving) its logic.

## 1. Triage the module

```bash
file mod.wasm                       # confirms "WebAssembly (wasm) binary module"
wasm-validate mod.wasm && echo ok   # well formed?
wasm-objdump -x mod.wasm            # sections: types, imports, functions, exports, memory, data
```
Read the export list first: it names the functions you can call from outside (often `check`,
`validate`, `main`, `malloc`, plus a `memory`). Read the import list: imports from `env` or `wasi`
tell you what the host must provide.

## 2. Get a readable view

```bash
wasm2wat mod.wasm -o mod.wat        # the text format, 1:1 with the binary
wasm-decompile mod.wasm -o mod.dcmp # C-like, easier for control flow and loops
```
Work from `mod.dcmp` for logic and drop to `mod.wat` when you need exact opcodes or operand order.

## 3. Read the data segment

```bash
wasm-objdump -s -j data mod.wasm    # raw bytes of the data section with their memory offsets
```
Constants the checker compares against (expected bytes, a key, a table) usually live here at a
fixed linear-memory offset. Note the offset; the code will `i32.load`/`i32.load8_u` from it.

## 4. Call the exports instead of reading everything

A keygen or checker is often fastest to drive dynamically. Node loads the module directly:

```js
// run: node drive.js
const fs = require('fs');
(async () => {
  const bytes = fs.readFileSync('mod.wasm');
  const { instance } = await WebAssembly.instantiate(bytes, {
    env: { /* stub any imported function the module needs */ }
  });
  const ex = instance.exports;
  // write input into linear memory, then call the export
  const mem = new Uint8Array(ex.memory.buffer);
  const input = Buffer.from('candidate');
  const ptr = ex.malloc ? ex.malloc(input.length) : 1024;
  mem.set(input, ptr);
  console.log(ex.check(ptr, input.length));   // observe the return
})();
```
In a browser, set a breakpoint in DevTools (the Sources panel shows the WAT) and call the export
from the console. See `Manuals/chrome-devtools/3. Contexto para Claude.md`.

## 5. When you must hand-decode

Lift to C and compile it, so you can print intermediate state:

```bash
wasm2c mod.wasm -o mod.c            # then compile with the wabt runtime headers and add prints
```

## 6. Validate your result

Recompute whatever the module checks (for example the expected-bytes comparison you found in the
data segment) and confirm the export returns the success value before trusting it.
